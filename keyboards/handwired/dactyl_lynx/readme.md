# handwired/dactyl_lynx

![handwired/dactyl_lynx](https://raw.githubusercontent.com/whitelynx/dactyl-lynx-keyboard/main/resources/skeleton-prototype.jpg)

The Dactyl Lynx is a parameterized, split-hand, concave, columnar, ergonomic keyboard.

This is my fork of [the original Dactyl](https://github.com/adereth/dactyl-keyboard).

* Keyboard Maintainer: [David H. Bronke](https://github.com/whitelynx)
* Hardware Supported: [STM32F4xx Blackpill](https://github.com/WeActStudio/WeActStudio.MiniSTM32F4x1), RP2040 TYPE-C 16MB
* Hardware Availability: [STM32F4xx Blackpill](https://www.aliexpress.com/item/1005005953179540.html), [RP2040 TYPE-C 16MB](https://www.aliexpress.com/item/1005003928558306.html?spm=a2g0o.order_list.order_list_main.23.42c018022ZKVRW)

See the `stm32` subdirectory to build for the STM32F4xx Blackpill, and the `rp2040` subdirectory to build for the RP2040 TYPE-C 16MB.
